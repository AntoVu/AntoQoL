# AntoQoL
1.20.1 forge mod QoL features

Requires Forge 47.2.0 and Cloth Config (`cloth-config-forge` 11.1.118).

## Features
 - Speed
 - Accelerator
 - Timer
 - Free Fly
 - No Slowdown
 - No Debuff
 - Reveal Invisible
 - Auto Crossbow
 - Entity Reach
 - Step
 - Auto Clicker
 - Criticals
 - No Fall
 - Freecam
 - ESP (glow outlines and tracers)
 - Fullbright
